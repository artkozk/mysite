# artkozk Cosmic Portfolio

Иммерсивный сайт-визитка Артемия Кожакина в космической стилистике: 3D-фон, интерактивные орбиты, гиперпереходы между темами и живые блоки с motion-эффектами.

## Что внутри

- `index.html` — структура секций, прелоадер, фоновые контейнеры, контентные блоки.
- `styles.css` — визуальный стиль, анимации, адаптив, мобильный dock.
- `script.js` — 3D-сцены (`three.js`), орбитальная физика, typewriter-эффекты, прогресс маршрута.

## Ключевые эффекты

- Плавный вход: cinematic-прелоадер с прогресс-метром, после чего интерфейс мягко “въезжает” в основную сцену.
- Фоновая 3D-сцена: центральная Земля + дальние планеты.
- Смена темы через взаимодействие с фоновой сценой:
  - вращение большой Земли,
  - клик по проявившимся дальним планетам (Earth / Neon / Ember),
  - warp-переход между системами.
- Две удалённые планеты проявляются в глубине сцены во время вращения фона и имеют расширенные hit-зоны для клика.
- Интерактивный блок менторов:
  - drag без «сопротивления»,
  - отскок соседних узлов,
  - фиксация выбранного узла в центре по клику,
  - выбор узла также через список приоритетов справа.
- Блок кода:
  - запуск печати при скролле до секции,
  - runtime-лента событий с фильтрами,
  - пульсирующие статусы.
- Маршрут секция: визуальный прогресс по мере скролла.
- Контентный слой кейсов:
  - блок доказательств (метрики + framework),
  - карточки кейсов с ролью/сроками/стеком,
  - trust-секция о том, как оформляются убедительные кейсы.

## Адаптив и мобильная логика

- На мобильных скрывается шумная терминальная подложка, чтобы не перекрывать контент.
- Хедер заменяется на нижний `mobile-dock` для быстрой навигации.
- Секция `Planetary Lab` не содержит отдельного canvas-поля: управление идёт через большую фоновую планету.
- Смена темы не происходит автоматически: требуется явный drag фона.
- Упрощены размеры орбитных узлов и канвасов.
- Снижена плотность звёздного поля для стабильной производительности.

## Кастомизация

### Тексты

- Редактируются в `index.html` (контент секций).

### Цветовые темы

- Токены в `styles.css`:
  - `:root`
  - `body.theme-neon`
  - `body.theme-ember`

### Скорость/характер анимаций

- Прелоадер и переходы: `script.js` (`finishPreloader`, `initPreloaderScene`).
- Полёт/тема планет: `script.js` (`initEarthScene`).
- Орбиты менторов: `script.js` (`initOrbitPhysics`).
- Печать кода и runtime: `script.js` (`initCodeTyping`).

## Технические заметки

- Используется `three.js` через ES module imports (`esm.sh`) в `script.js`.
- 3D-модель ракеты и текстуры Земли подгружаются с CDN.
- Есть fail-safe прелоадера (`window.__forceHidePreloader`) на случай сетевых/JS ошибок.
- Для обхода агрессивного кеша подключены версии ресурсов: `styles.css?v=...` и `script.js?v=...`.

## Что можно улучшить дальше

- Перенести тексты/сниппеты в JSON-конфиг.

- Почему так:
  - Пользователь не должен видеть «моргание» контента до прелоадера.

- Почему так:

  - Новая схема делает поведение предсказуемым для пользователя.
